Transcription of Mauritius Census Data

Project Objective

The goal of this project was to recreate a 2011 census map that identifies the major dominant religions in Mauritius by ward. The original map was only available via a Reddit post, and no official ward-level data (polygons) were publicly published.

Primary Workflow

  1. Contact the Mauritius Census Department to request the official boundary file for wards.
  2. Update the attribute table of the wards data by manually transcribing religion data from the Reddit map image into an ArcGIS feature class.
  3. Create a final visual representation of the data in ArcGIS Pro to reflect dominant religions by ward.
  4. All work was performed in ArcGIS Pro
